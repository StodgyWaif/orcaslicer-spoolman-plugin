# Field Mappings

Field mappings connect a SpoolMan source path to a supported OrcaSlicer preset target.

## Source examples

```text
spool.location
spool.extra.date_acquired
filament.density
filament.settings_extruder_temp
filament.extra.flow_ratio
vendor.name
```

Use **Show All SpoolMan Fields** to review built-in and custom source paths, types, units, populated counts, and samples before changing mappings.
