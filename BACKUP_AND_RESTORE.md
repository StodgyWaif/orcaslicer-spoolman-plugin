# Backup and Restore

Use the plugin's backup tools before large imports, synchronization, cleanup, upgrades, or computer migration.

The backup and restore workflow documented for v1.0.72 was tested on **OrcaSlicer 2.5.0-dev**.

Before restoring on another computer, select and validate the destination OrcaSlicer filament folder. Do not assume a source-computer path is valid on the destination.
