# Installation

## Local installation

1. Download `spoolman_plugin.py` from the desired GitHub release.
2. Open OrcaSlicer.
3. Open **File > Plugins** or the Plugins window for the installed OrcaSlicer version.
4. Use **Install local plugin** and select `spoolman_plugin.py`.
5. Refresh the plugin list or restart OrcaSlicer.
6. Confirm **SpoolMan Importer** appears and reports the expected version.

## Upgrade

1. Create a full plugin backup from Settings.
2. Preserve the currently working plugin file separately.
3. Install or replace the plugin with the new `spoolman_plugin.py`.
4. Fully restart OrcaSlicer.
5. Confirm the version and run a basic inventory refresh.

## First-run checklist

- Enter the SpoolMan URL.
- Test the connection.
- Confirm the OrcaSlicer user filament folder.
- Discover SpoolMan fields.
- Review field mappings.
- Run Import Preview before importing.

## Removal

Use OrcaSlicer's Plugins window to remove the local plugin. Removing the plugin does not automatically remove generated presets or backup files.
